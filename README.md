# 🏥 CUER Nursing Booking App

A production-style Flutter application for booking home-care nursing services.  
Built using **Flutter, BLoC (Cubit), and Clean Architecture principles**.

---

## 🚀 Features

### 🔐 Authentication
- User registration and login using Firebase Auth
- Password reset functionality
- SeCUER session handling

---

### 🏥 Booking System
- Service selection (Nurse Visit, Injection, Elderly Care)
- Date picker integration
- Notes input for patient requirements
- Step-by-step booking flow (Stepper UI)
- Booking validation before submission
- Success / Error state handling

---

### 📋 My Bookings
- View all user bookings
- Categorized status:
  - Upcoming
  - Completed
- Clean list UI with status indicators

---

### 📊 Dashboard (UI Layer)
- Basic dashboard cards for app overview
- Modular UI components
